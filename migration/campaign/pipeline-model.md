# Dry Run Campaign and Pipeline Model

## Flow

```text
REAL EVENT OR PLANNED CAPTURE NEED
  → CONTENT OPPORTUNITY
  → STORY ANGLE
  → FORMAT
  → OPERATIONAL CTA
  → AUDIENCE RESPONSE
  → LEARNING
```

## Human statuses

`Ý tưởng` → `Đang chuẩn bị` → `Đang quay/chụp` → `Đang dựng` → `Sẵn sàng` → `Đã đăng`

Side exits: `Tạm dừng`, `Bỏ`.

## Initial source-bounded capture needs

1. Record one real Dry Run event and the adjustment it caused.
2. Capture one verified preparation detail and explain its intended experience.
3. Record one current working standard only after the operational owner confirms it.

These are capture requirements, not claims that the events, assets, or standards already exist.

## Update rule

Business-state change can reprioritize any item. The calendar never becomes the master.
Results remain lightweight: reach/views, saves, shares, comments, notable Inbox response,
and what was learned.
