# TOPLINK_RUN1_BUILD — master prompt

## Invocation boundary

Use only for the `TL-M1`–`TL-M5` package after its predecessor gates and `TL-M0` readiness permit
work. Read `AGENTS.md`, `STATE.md`, `RULES.md`, `task.md`, `GOVERNANCE.md §1 + §3`, the active
milestone, and exact evidence inputs. This prompt cannot authorize external mutation or replace a
real DMP invocation.

## Non-negotiable inputs

- Active DMP brand must read back as `toplink-y-vien`.
- Record DMP version, skill, timestamp, trace ID, exact input paths/digest, output paths/digest,
  status, and skipped dimensions. `NO_TRACE = NOT_DONE`.
- Classify all material statements as confirmed, inference, hypothesis, missing, unverified, or
  do-not-use. Do not invent franchise/legal, founder, product, service, medical, availability,
  performance, price, booking, qualification, or nationwide-capacity facts.
- Google Sheets is `BLOCKED_TARGET_INPUT`; no Page, Sheet, publishing, messaging, or external
  runtime mutation is allowed without separate exact approval.

## Claude Phase A — author and hand off

1. Acquire the scoped `task.md` lease and record scope, non-goals, output paths, stop conditions,
   reviewer route, and verification contract.
2. Run only the required DMP skills from the Toplink milestone contract. Save output to local
   staging and preserve the trace; do not call a skill-contract review a real invocation.
3. Coordinate the routed Agency reviewers (maximum three per workstream). Preserve issue,
   severity, evidence/location, repair request, and verdict.
4. Keep health/legal/privacy/public-claim items as `NEEDS_HUMAN_REVIEW`; no reviewer or runtime
   may mark them `APPROVED`.
5. Prepare `handoff-claude-to-codex.md` and `handoff-envelope.json` from the committed templates.
   State exact paths/digests, stable IDs, open issues, gates, allowed next action, and forbidden
   actions. Stop writing, checkpoint, and release the lease.

## Codex Phase B — reconcile locally

1. Acquire a new scoped lease only after Claude has released its row. Validate the active brand,
   DMP version, scope, source/profile/output digests, trace, and handoff provenance.
2. Reconcile evidence/status/allowed-use maps, stable identity, cross-workstream consistency,
   schema, Unicode, secret/PII, safety, and diff hygiene.
3. Apply only evidence-grounded targeted repairs. New substantive strategy, creative, or
   health-sensitive content requires the correct DMP authoring route; Codex must not invent it.
4. Record reviewer outcomes and repairs in a stable issue ledger. Create the Run 1 manifest from
   `docs/system/templates/toplink-run-manifest.template.json`.
5. Do not promote canonically, write externally, create `_v2`, begin Run 2, or open TL-M6. Persist
   blockers/gates and release the lease at the Run 1 checkpoint.

## Run 1 exit contract

`RUN_1_PASS` requires valid local provenance, trace, review records, stable IDs, local checks, an
honest manifest, and unresolved human gates preserved. Any brand/digest/scope conflict, missing
required evidence, conflicting lease, or second repeated bounded failure is a stop—not a pass.
