# Prompt and run contracts

Store milestone-specific DMP/run contracts and review prompts here. A prompt is not evidence and
cannot override `RULES.md`, the master plan, or the milestone contract.

## Committed Toplink contracts

- `TOPLINK_RUN1_MASTERPROMPT.md` covers Claude DMP authoring and Codex reconciliation, ending in
  a Run 1 local manifest.
- `TOPLINK_RUN2_MASTERPROMPT.md` covers the fresh Claude/Codex audit-finalize sequence with paired
  validation and conditional bounded sync.
- Actual per-run artifacts belong in local staging and start from `docs/system/templates/`; never
  edit these master prompts to record a run result.
