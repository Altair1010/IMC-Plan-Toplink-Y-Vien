# Scaffold audit

## Inherited structure

- Fresh Trellis 0.6.8 initialization with Claude, Cursor, and Codex integration.
- Trellis workflow skills and three workflow agents.
- Six project-local marketing Agency Agents selected by the source project.
- Git safety files, root control plane, docs layers, DMP capability inventory, and routing matrix.

## Deliberately excluded

- Thảo Tây strategy/content deliverables, root history, staging data, local caches, backups,
  secrets, credentials, external target identifiers, and Git history.
- The full Agency Agents vendor collection and unneeded DMP capability catalog.

## Target-specific substitutions

- `spec.md`, `RULES.md`, and system docs use Toplink’s canonical plan, milestone contract,
  evidence model, brand slug, Page-first channel model, and fail-closed safety rules.
- `.trellis/` is newly initialized; it does not inherit Thảo Tây’s journal, developer state,
  task archive, or generated hashes.

## Regenerated standalone controls

- `AGENTS.md`, `CLAUDE.md`, `GOVERNANCE.md`, `RULES.md`, and `LOOP.md` now carry Toplink-specific
  lease, handoff, two-run, approval, scope, lifecycle, and close rules.
- `docs/system/claude-codex-operating-contract.md` is the single coordination owner; committed
  handoff and manifest templates support actual run artifacts without copying historic staging.
- `STATE.md`, `MEMORY.md`, `task.md`, `README.md`, and `docs/prompts/` have a common read order and
  explicit boundary between active state, durable memory, prompts, and canonical strategy.

## Still intentionally not ported

- Environment-specific hooks, local MCP configuration, settings.local, connector binaries, caches,
  data fixtures, Sheet/Page targets, staging output, automation scripts, and execution history.
- Brand strategy/content output, product facts, legal/franchise assertions, health claims, and
  analytics baselines from any other project.
