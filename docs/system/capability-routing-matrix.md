# Capability routing matrix

| Workstream | DMP | Reviewer route | Required artifact control |
|---|---|---|---|
| Evidence/source grounding | `import-guidelines`, `brand-setup` | PR Manager | provenance, status, allowed-use, input gaps |
| Audience and positioning | `audience-intelligence`, `campaign-plan` | Social Strategist → Growth Hacker | hypotheses, validation path, no invented insight |
| Facebook/pillar strategy | `social-strategy` | Social Strategist + Content Creator | 3–5 pillars, 100% weights, Hanoi/national boundary |
| Narrative and copy | `content-engine` | Content Creator → PR Manager | source-grounded copy, reputation and claim gate |
| Calendar and production | `content-calendar`, `content-engine` | Content Creator → PR Manager | capacity, approval state, no fabricated date |
| Reels | `video-script` | Short-Video Coach → TikTok Strategist | mechanics reference, originality, no TikTok primary scope |
| KPI and experiments | `campaign-plan` | Growth Hacker | greenfield logic, no percent growth from zero |
| Safety and approval | `check`, `status` | PR Manager → human/professional | `NEEDS_HUMAN_REVIEW`, never self-approve |
| Sheets sync | `output-folder`, `integrations` | operator only | approved target, stable ID, exact read-back |
